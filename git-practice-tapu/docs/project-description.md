# Project Overview

## Purpose
The primary objective of this project is to gain hands-on proficiency in source code management using Git and remote collaboration on GitHub.

## Workflow Implemented
- **Local Initialization:** Creating repository structure and tracking files.
- **Gitignore Integration:** Preventing unnecessary and environment-specific files from tracking.
- **Branching Workflow:** Isolated feature development (`feature/calculator`) followed by integration into the `main` branch.
- **Utility Modules:** Basic Python utilities providing arithmetic operations.
